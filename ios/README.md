# Skyjo Native iOS Workspace

The Xcode project has not been bootstrapped yet. Start with [the portable native handoff](../docs/native-ios/README.md), run `../scripts/ios-preflight.sh` from this directory (or `./scripts/ios-preflight.sh` from the repository root), and work [GitHub issue #181](https://github.com/chadmhohn/skyjo-online/issues/181).

Issue #181 owns the initial `SkyjoNative.xcodeproj`, configuration chain, Swift package boundaries, schemes, test plan, and macOS CI. Do not create an unrelated proof-of-concept project or a web-view wrapper beside it.
