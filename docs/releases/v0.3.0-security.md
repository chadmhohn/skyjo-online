# v0.3.0 security disposition

v0.3.0 changes the solo menu, local IndexedDB metadata, and client/server AI selection. It does not change schema version 2, multiplayer protocol version 2, the room wire contract, server authentication, invite semantics, or production database migrations. Additive `aiSetup` session metadata remains readable and safely ignorable by v0.2.2.

## Release dependency gate

`npm run audit:release` is release-blocking at the exact protected-main and tag SHAs. It requires zero high and critical findings and permits only this reviewed moderate set:

- `react-router`: [GHSA-wrjc-x8rr-h8h6](https://github.com/advisories/GHSA-wrjc-x8rr-h8h6) and [GHSA-337j-9hxr-rhxg](https://github.com/advisories/GHSA-337j-9hxr-rhxg);
- `react-router-dom`: [GHSA-jjmj-jmhj-qwj2](https://github.com/advisories/GHSA-jjmj-jmhj-qwj2), plus its inherited `react-router` findings.

The gate fails for a new or removed moderate package, any different moderate advisory URL, any high/critical finding, an unreadable audit response, or a build after **2026-08-21 23:59 UTC**. CodeQL must also pass at the exact protected-main and immutable tag SHAs.

Skyjo uses a client-only `BrowserRouter` and does not execute the affected SSR hydration deserializer. Most `Link` destinations are fixed same-origin paths, but the existing post-auth `next` query value is user controlled and accepted when it begins with `/`; that check does not exclude every affected backslash or protocol-relative redirect variant. The client-routing advisories therefore remain an explicitly accepted residual risk. v0.3.0 adds no externally controlled `Link`, `useNavigate`, post-auth destination, or navigation target. The exception does not authorize broadening that surface and must be replaced by a separately reviewed React Router 7 migration with hostile `next` path tests before expiry.

## Data and browser boundaries

- AI strategy receives a typed redacted knowledge projection; hidden draw/card values are not exposed to a bot strategy, DOM, log, or release evidence.
- Exact-SHA AI evidence contains only bounded synthetic benchmark measurements and is checksummed before certification references it.
- The public production PWA smoke uses a fresh credentialless browser context, creates only a disposable guest IndexedDB session while offline, sends no mutating request, and discards that context afterward.
- Cache Storage remains a strict public-resource allowlist. APIs, rooms, login, invites, cookies, game records, and account/user data are never cached.
- Production deploy credentials are removed from the Playwright child's environment. The smoke creates no traces, screenshots, or videos.

Runtime archive, checksum, SBOM, and provenance must be rebuilt from the immutable tag. Application secrets remain only in `/etc/skyjo-online.env` and are never copied to GitHub or browser evidence.
