# v0.3.4 security addendum

v0.3.4 adds source-only native multiplayer and universal-link consumers plus their build/test harnesses. Production dependencies remain unchanged, and public database schema 2, room persistence 2, multiplayer protocol 2, and contract bundle 1 remain stable.

- The release does not create or use `apns_devices`, accept device tokens, load APNs provider credentials, or make Apple provider calls. It preserves the exact optional table validator and artifact-only certification helper required by #203. Normal `server.mjs` startup never imports it, and the proof requires both servers to exit cleanly after SIGTERM.
- Native invite redemption grants only the existing outer access session. Account authentication and room membership remain mandatory; a universal-link tap routes to explicit review and never auto-joins a seat.
- Associated Domains contains only the production invite host. Build auditing rejects entitlement drift, redirects remain a browser fallback, and signing identities, provisioning profiles, Apple credentials, and device identifiers stay outside git and retained evidence.
- Release and deployment credentials remain bound to the current authorized account and least-privilege workflow. CodeQL does not run automatically on tag pushes, so the exact protected-main result remains mandatory.
- The annotated tag and production promotion require current-conversation approval naming `v0.3.4` and its exact SHA; general autonomy is insufficient. Rollback remains code-only and must never restore live state.
