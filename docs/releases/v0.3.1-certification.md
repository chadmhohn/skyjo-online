# Skyjo v0.3.1 patch release certification

Immutable `v0.3.0` remains at `3e7f7abc1fabda77587d0fd00960e68e0006a87e`. Its application smoke passed after promotion, but the credentialless PWA gate mistook Cloudflare Web Analytics' same-origin `POST /cdn-cgi/rum` for an application mutation. Automatic rollback restored healthy `v0.2.2`; `v0.3.0` must not be moved, deleted, or published.

## Scope and reusable product evidence

`v0.3.1` changes only test/release policy, its deterministic regressions, release identity, workflows, changelog, and release documentation. It does not change `src/`, `server.mjs`, `server-release.mjs`, `public/`, `deploy/`, production dependencies, schema version 2, or multiplayer protocol version 2. Review must explicitly confirm that runtime-equivalence boundary.

The three independent `v0.3.0` persona passes and the physical `PASS V0.3 IOS` session on 2026-07-26 remain valid product evidence because no application behavior changed. They may be reused for this patch. The protected-main `v0.3.1` SHA must still run the complete automated CI and CodeQL matrix, including fresh unit, browser, accessibility, visual, Lighthouse, AI calibration, load, recovery, canary, artifact, attestation, and public-PWA evidence. Automated evidence must identify release `0.3.1` and the new exact SHA; no `v0.3.0` automated artifact may substitute for it.

## Release gates

1. Verify the request-policy regression permits `GET`, `HEAD`, and `OPTIONS`, plus only same-origin `POST /cdn-cgi/rum` or `/cdn-cgi/rum/` with no query/fragment and no URL credentials. Browser resource-type variation (`xhr`, `fetch`, `ping`, or equivalent) must not change that exact URL/method decision. Every application, lookalike, off-origin, malformed, or other-method request must fail with a sanitized reason code.
2. Preserve the existing credentialless cookie, strict cache allowlist, offline cold-launch, disposable guest-session, and exact Continue/restore assertions.
3. Squash issue #174 to protected main, freeze that commit as `CERT_SHA`, and require every protected-main check plus CodeQL to pass at it.
4. Run `npm run certify:verify -- --release-sha "$CERT_SHA"` with fresh checksummed `v0.3.1` AI, automated, recovery, and RSS evidence from that SHA.
5. Create immutable annotated tag `v0.3.1` exactly at `CERT_SHA`. Require tag CI, canary, production promotion, credentialless public-PWA smoke, and incident recovery to pass.
6. Re-run the verifier with `--tag v0.3.1 --production-base-url https://skyjo.groundworkrevops.com`, confirm public schema/protocol 2/2 and the exact SHA, then publish the GitHub Release. Rollback remains code-only; never restore a live database automatically.
