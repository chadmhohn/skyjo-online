# v0.2.2 security disposition

v0.2.2 changes public audio assets and client-side playback behavior; it does not add a runtime dependency, server endpoint, protocol field, database migration, credential, or new user-data cache surface. The HTML policies add `media-src 'self' data:` solely so locally generated WAV fallback tones can play when Web Audio is unavailable; script, style, connection, frame, and object policies are unchanged.

## Release requirements

- `npm audit --audit-level=high` must report zero high and critical findings at the exact protected-main and tag SHAs.
- CodeQL must pass at the exact protected-main and immutable tag SHAs.
- Workbox may precache only the allowlisted public cue files. API, room, invite, authentication, cookie, and user-data responses remain excluded.
- Both server-rendered and static application HTML must constrain media to same-origin files and inert `data:` audio; no remote media origin or `blob:` source is allowed.
- Audio diagnostics and failure paths must not log game state, card values, room codes, account identifiers, or credentials.
- The runtime artifact and SBOM must be rebuilt and attested from the exact tag.

## Moderate React Router exception

The reviewed v0.2.1 React Router disposition remains unchanged. `react-router-dom` 6.30.4 has moderate client-routing advisories whose available remediation requires the separately tested React Router 7 migration. Skyjo does not use the affected SSR hydration path, while the client redirect exposure remains bounded by fixed same-origin route construction and the existing local-path control.

This exception:

- covers only the React Router advisories already documented in [v0.2.1-security.md](v0.2.1-security.md);
- does not cover any new moderate, high, or critical advisory;
- prohibits new externally controlled navigation destinations; and
- expires at **2026-08-21 23:59 UTC**.

If a new advisory appears, the high/critical audit gate fails, or the candidate is built after the expiry, release work stops until a new reviewed disposition or compatible fix exists.
